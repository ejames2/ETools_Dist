## Exploration Tab

![Exploration Tab](https://github.com/user-attachments/assets/ee8b22d7-e772-4079-99fe-ba710529d882)

This tab displays all explored bodies in the current system, including:

- **Body**: Clicking a body name opens a detailed information view for that body.
- **Bookmarks (B column)**: Create or view bookmarks associated with the selected body.
- **Class**: The planet or body classification.
- **Distance**: Distance from the system entry point (measured in light-seconds).
- **Value**: Estimated scan value of the body. The current value is shown first, followed by the mapped value in parentheses.
- **Status Icons**: Various icons provide additional information about the body, including:
  - Unmapped
  - Volcanism
  - Atmosphere
  - Landed On
  - Walked On
  - Gravity (for landable bodies)
  - Biological signals
  - Surface mining locations
  - Planetary rings with calculated ring density

  Hover over an icon to view additional details.

- **Other**: Lists discovered ring hotspots and scanned biological signals.

## Bookmark Tab

![Bookmark Tab](https://github.com/user-attachments/assets/6edef732-db96-4ba6-8e3b-5c4ee47deb1b)

Bookmarks are organized into folders. Within each folder, bookmarks are automatically sorted by distance from your current location.

Bookmarks can be edited and may be attached to either a star system or a specific planetary body.

## Asteroid Mining Tab

### Last Prospect

Displays prospecting information for the most recently prospected asteroid.

### Cargo

Displays your current cargo inventory and the amount of remaining cargo space on your ship.

## Search Tab

The Search tab provides several tools for locating systems, previously explored locations, and mining opportunities.

### Search System

Search for and display information about a specific star system.

![Search System](https://github.com/user-attachments/assets/30415a50-3f28-4461-b5d2-d229bac1276a)

### Nearest System List

Enter a search radius (in light-years) and the maximum number of results to generate a list of nearby systems that you have previously explored.

Results are sorted by distance from your current location, from nearest to farthest.

![Nearest System List](https://github.com/user-attachments/assets/07632123-a521-4e36-9eb6-6c90694ca734)

### Nearby Ring Hotspots

Enter a search radius (in light-years) and the maximum number of results to generate a list of nearby planetary bodies containing ring hotspots that you have scanned.

Results are sorted by distance from your current location, making it easy to locate previously discovered mining opportunities.

![Nearby Ring Hotspots](https://github.com/user-attachments/assets/ce2bc3fa-de76-44a2-8513-ad78788d2c69)
