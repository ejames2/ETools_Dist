# ETools_Dist

ETools is a companion application for Elite Dangerous and is intended to be ran in a separate monitor while you play the game.

It currently has tools for:
* Exploration - including estimated income from biological samples.
* Asteroid mining
* A bookmarking system
* Limited search capability.
* Future Surface Mining.


## Exploration Tab
<img width="2299" height="1305" alt="image" src="https://github.com/user-attachments/assets/ee8b22d7-e772-4079-99fe-ba710529d882" />

This tab displays all explored bodies in the current system including the following:
* The `Body` name.  Clicking in the body name will bring up more detailed information on that body.
* A bookmark icon for viewing or creating a bookmark for the given planetary body in the `B` column.
* The planets `Class`.
* The `Distance` of this body from the system entry point in Ls.
* The estimated `Value` of the body.  The current value followed by the potential mapped value in parenthesis.
* Various icons created for the body including: Unmapped, Volcanism, Atmosphere, Landed On, Walked On, Gravity (for landable bodies), Organics, Surface mining locations and planetary rings with calculated ring density. Hovering over these icons will display more information.
* The `Other` column lists any discovered ring hot spots and any scanned biologicals.



## Bookmark Tab
<img width="2317" height="1510" alt="image" src="https://github.com/user-attachments/assets/6edef732-db96-4ba6-8e3b-5c4ee47deb1b" />

Bookmarks are stored in folders and each folder displays it's bookmarks in order of distance from your current location.
The bookmarks are editable, and can be attached to either a system or a planetary body.

## Asteroid Mining Tab

### Last Prospect
Displays the prospecting information for the last asteroid prospected.

### Cargo
Displays your cargo and the amount of free space on your current ship.

## Surface Mining Tab

This will keep track of surface mining locations and the deposits in those locations.
It will also display a live map of the current surface location with the deposits and your position maked.
